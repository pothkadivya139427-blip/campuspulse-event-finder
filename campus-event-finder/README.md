# CampusPulse – AI-Based Campus Event Finder and Registration Assistant

A responsive web application that helps students discover, search, filter and register for campus events,
view them in a calendar, track registrations, and ask an event assistant for suggestions.

## Features
- Dashboard with event summary
- Event listing with search and category filter
- Register / cancel registration (saved in browser localStorage)
- Monthly event calendar
- Event assistant (keyword-based suggestions)
- My Registrations page
- Responsive layout for desktop and mobile

## Technologies
HTML, CSS, JavaScript, localStorage

## How to run
Open `index.html` in any web browser. No installation needed.

## Publish on GitHub Pages
1. Create a new GitHub repository and upload `index.html` and `README.md`.
2. Go to Settings → Pages.
3. Under "Build and deployment", choose Deploy from a branch → `main` → `/ (root)` → Save.
4. After a minute your site is live at `https://<username>.github.io/<repository-name>/`.
